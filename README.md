# Python Package Manager

Yep, yet another package manager—worse and less performant than the others. But hey, this one's in Python... the beginner's language!

All jokes aside, I learned to code two months ago and I built something that, according to me (and *only* me), is actually "good". It manages dependencies, runs cross-platform (Windows, Linux, and macOS if I set up repos for it), and supports multiple repositories (one day I'll write a full doc on how to set one up, but *only* one day). For now, you can already add repos, install any app available in your added repos, uninstall packages, use a list system (I'll document this later...), and update both the repositories and the app itself. Not too bad for someone who's only been coding in Python for two months...
